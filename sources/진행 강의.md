

#### 🔹 엑셀 기본기 시리즈

**AI 시대에도 살아남는 일머리 엑셀 — 입문** _"AI한테 시키려면, 나도 알아야 한다"_ 실무에서 가장 많이 쓰는 핵심 기능만 압축해서 익히는 과정

- 업무 속도를 2배로 만드는 실무 단축키
- 지저분한 데이터 정리하기 (데이터 클렌징·가공)
- 안 쓰면 손해 보는 실무 함수 BEST
- 3초 만에 보고서 만드는 피벗테이블 첫걸음

**AI 시대에도 살아남는 일머리 엑셀 — 실전** _입문 과정 수료자 또는 기본기를 갖춘 실무자 대상_ 혼자서는 막히던 업무를 스스로 해결할 수 있는 수준으로

- 데이터분석에 필요한 다양한 시각화
- VLOOKUP·XLOOKUP, ifs, countifs, sumifs 활용한 중첩 함수 로직 구현
- 피벗테이블로 보고서 끝내기
- **클로드와 함께하는 실무 엑셀 — AI에게 똑똑하게 일 시키기** (수식·함수 요청 프롬프트 작성법, 데이터 분석·보고서 작성 활용법, AI가 잘하는 일과 못하는 일 구분하기)

#### 🔹 AI 자동화 종합반

**클로드 코워크로 시작하는 엑셀 업무 자동화** _"엑셀을 잘 다루는 사람"에서 "엑셀을 시키는 사람"으로_

**1부. 클로드 웹 — AI 비서 처음 만나기**

_클로드에게 잘 시키는 법_

- 프롬프트 작성 원칙 (좋은 예시 vs 나쁜 예시)
- Claude vs Gemini, 같은 업무에서 결과 품질 비교

_클로드 웹 실무 활용_

- 여러 파일·시트 데이터 통합
- HTML 시각화 대시보드 만들기
- PDF·이미지를 엑셀로 변환·정리

_커넥터로 일하는 환경 통째로 연결하기_

- Gmail·캘린더·슬랙 커넥터 실무 활용
- 메일 요약, 일정 자동 등록 시나리오

_클로드 웹의 한계_

- 업로드 개수·토큰 제약
- 자동화로 넘어가야 하는 순간

---

**2부. 클로드 코워크 — 내 컴퓨터를 AI에게 맡기기**

_코워크 이해하기_

- 클로드 웹과 무엇이 다른가
- 로컬 파일을 직접 읽고 작업하는 구조

_기본 활용_

- 월별 매출 파일 한 번에 통합하기
- 지점별 흩어진 파일 자동 정리
- 폴더 정리 자동화 (파일명 규칙·분류·이동)

_코워크의 진짜 힘 — 반복을 없애는 자동화_

- 자주 쓰는 작업을 "스킬"로 저장하기
- 스케줄 반복 실행 자동화

_풀 워크플로우 자동화 시나리오_

- 파일 감지 → 통합 → 분석 → 리포트 작성 → 메일·슬랙 발송까지 한 번에
