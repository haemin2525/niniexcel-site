# AI 자동화 종합반 — 클로드 코워크로 엑셀 업무 자동화

> "엑셀을 잘 다루는 사람" → "엑셀을 시키는 사람"으로. 단발 AI 호출이 아니라 **반복 업무 통째로 위임**하는 단계.

## 1부. 클로드 웹 — AI 비서 처음 만나기

### 클로드에게 잘 시키는 법
- 프롬프트 작성 원칙 (좋은 예시 vs 나쁜 예시)
- Claude vs Gemini, 같은 업무에서 결과 품질 비교

### 클로드 웹 실무 활용
- 여러 파일·시트 데이터 통합
- HTML 시각화 대시보드 만들기
- PDF·이미지를 엑셀로 변환·정리

### 커넥터로 일하는 환경 통째로 연결
- Gmail·캘린더·슬랙 커넥터 실무 활용
- 메일 요약, 일정 자동 등록 시나리오

### 클로드 웹의 한계
- 업로드 개수·토큰 제약
- 자동화로 넘어가야 하는 순간

## 2부. 클로드 코워크 — 내 컴퓨터를 AI에게 맡기기

### 코워크 이해하기
- 클로드 웹과 무엇이 다른가
- 로컬 파일을 직접 읽고 작업하는 구조

### 기본 활용
- 월별 매출 파일 한 번에 통합하기
- 지점별 흩어진 파일 자동 정리
- 폴더 정리 자동화 (파일명 규칙·분류·이동)

### 코워크의 진짜 힘 — 반복을 없애는 자동화
- 자주 쓰는 작업을 "스킬"로 저장하기
- 스케줄 반복 실행 자동화

### 풀 워크플로우 자동화 시나리오
- 파일 감지 → 통합 → 분석 → 리포트 작성 → 메일·슬랙 발송까지 한 번에
